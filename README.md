# Python Mini Projects

A collection of small Python projects created to practice programming concepts and graphical user interface development.

## Projects

### Tic-Tac-Toe

A graphical Tic-Tac-Toe game built with **Python and Tkinter**.

The game supports Player vs. Computer and Player vs. Player modes, with simple rule-based logic used for computer moves.

[View Project](./tic_tac_toe)

## Technologies

- Python
- Tkinter
