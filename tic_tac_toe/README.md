# Tic-Tac-Toe

A graphical Tic-Tac-Toe game built with **Python and Tkinter**.

The game supports:

- Player vs. Computer
- Player vs. Player
- X or O selection
- First-player selection
- Automatic win and draw detection

In Player vs. Computer mode, the computer follows simple rule-based logic to:

- Make a winning move when available
- Block the opponent
- Prefer the center
- Choose corners when available
- Select another available position when necessary

## Technologies

- Python
- Tkinter
